# IEUM Daily Investment Trends — invest.ieumvc.com

Static site (GitHub Pages) for IEUM Value Creator's daily market brief.

## Layout
- `index.html` — latest brief (reads `data/latest.json`, `content/latest.json`, `archive/index.json`)
- `<YYYY-MM-DD>/index.html` — archive pages, generated by `scripts/build.py`
- `content/<date>.json` — the day's commentary (EN/KR): headline, regime, posture, IEUM's read, watchlist, catalysts, sources
- `data/<date>.json` — market snapshot written by `scripts/fetch.py` (Alpha Vantage: 10Y, USD/KRW, Brent, EOD quotes)
- `assets/` — `style.css`, `app.js` (no frameworks)
- `.github/workflows/daily.yml` — 07:30 KST Mon–Fri: fetch → build → commit

## Daily routine
1. The workflow fetches the data snapshot automatically (secret `ALPHAVANTAGE_API_KEY` required).
2. Add `content/<date>.json` for the day's brief, run `python scripts/build.py`, commit and push — or trigger the workflow after pushing the content file; it runs `build.py` too.

## Setup (once)
1. Repository → Settings → Secrets and variables → Actions → New repository secret `ALPHAVANTAGE_API_KEY`.
2. Settings → Pages → Source: Deploy from a branch, `main` / `/ (root)`; Custom domain `invest.ieumvc.com`; Enforce HTTPS.
3. DNS (Squarespace Domains): CNAME `invest` → `jayjayjang.github.io`.
4. Actions → "Daily market data" → Run workflow, to take the first full snapshot.

Free Alpha Vantage key: 25 calls/day — the workflow uses 8.
