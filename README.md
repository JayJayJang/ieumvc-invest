# IEUM Daily Investment Trends — invest.ieumvc.com

Static site (GitHub Pages) for IEUM Value Creator's daily market brief.

## Layout
- `index.html` — latest brief (reads `data/latest.json`, `content/latest.json`, `archive/index.json`)
- `<YYYY-MM-DD>/index.html` — archive pages, generated by `scripts/build.py`
- `content/<date>.json` — the day's commentary (EN/KR): headline, regime, posture, IEUM's read, watchlist, catalysts, sources
- `data/<date>.json` — market snapshot written by `scripts/fetch.py` (Alpha Vantage: 10Y, USD/KRW, Brent, EOD quotes)
- `assets/` — `style.css`, `app.js` (no frameworks)
- `.github/workflows/daily.yml` — 07:30 KST Mon–Fri: fetch → build → commit

## Daily routine
1. The workflow fetches the data snapshot automatically (secret `ALPHAVANTAGE_API_KEY` required).
2. Add `content/<date>.json` for the day's brief, run `python scripts/build.py`, commit and push — or trigger the workflow after pushing the content file; it runs `build.py` too.

## Price rules (no estimates)
Every price, close and yield in a brief is a published, final figure. If one cannot be confirmed, write "not confirmed" — never derive, interpolate or carry an intraday print as a close.
- **Korean stocks and indices** — KRX regular-session close (15:30). Source: Daum Finance daily quotes (`finance.daum.net/api/quote/A<code>/days`). Do not use Naver Pay prices: they mix in Nextrade (NXT) pre-/after-market trades and differ from the KRX close. Intraday and after-market press prints are not closes.
- **US Treasury yields** — US Treasury daily par yield curve (`home.treasury.gov`, daily treasury rates CSV). Use these for any day the Alpha Vantage series has not caught up to; do not use press approximations ("about 14bp", "just under 5%").
- **US equity closes** — Alpha Vantage EOD quotes in `data/<date>.json`; index levels from a named press source with its timestamp.
- **Investor flows, USD/KRW day-session close** — press-quoted KRX/market figures with source and time.
- If the morning workflow logs `failed` series in `data/<date>.json`, re-fetch them before writing the brief rather than relying on carried-forward values.
- **52-week highs/lows** — adjusted for corporate actions (bonus issues, splits), taken from the KRX daily series; label them "adj." with the date set.
- Tag every watchlist price with its source and session (e.g. "KRX close 22 Oct (Daum Finance)").

Data (KRX regular-session close and foreign ownership, no API key needed; send a browser User-Agent and `Referer: https://finance.daum.net/quotes/A<code>`):
- Daily closes: `https://finance.daum.net/api/quote/A<code>/days?symbolCode=A<code>&page=1&perPage=3&pagination=true` — use `tradePrice`, `changeRate`, high/low, volume.
- Foreign ownership and investor net buying: `https://finance.daum.net/api/investor/days?symbolCode=A<code>&page=1&perPage=3` — use `foreignOwnSharesRate`, `foreignStraightPurchaseVolume`, `institutionStraightPurchaseVolume`. Its `tradePrice` mixes in NXT trades, so do not take prices from it.
- Index closes and flows: `https://finance.daum.net/api/market_index/days?page=1&perPage=3&market=KOSPI|KOSDAQ&pagination=true`.

## Setup (once)
1. Repository → Settings → Secrets and variables → Actions → New repository secret `ALPHAVANTAGE_API_KEY`.
2. Settings → Pages → Source: Deploy from a branch, `main` / `/ (root)`; Custom domain `invest.ieumvc.com`; Enforce HTTPS.
3. DNS (Squarespace Domains): CNAME `invest` → `jayjayjang.github.io`.
4. Actions → "Daily market data" → Run workflow, to take the first full snapshot.

Free Alpha Vantage key: 25 calls/day — the workflow uses 8.
